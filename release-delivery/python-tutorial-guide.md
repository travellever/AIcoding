## 内容与功能

基于102页PDF重排，保留99个来源内容页，重建95个目录节点，整理139组配图。原文英文正文按章节、项目和操作步骤连续阅读。首页、搜索、导航、按钮、图注、动态提示及包内说明已全部改为英文。

支持目录跳转、全文搜索、代码复制、字号调整、图片放大/切换、手机目录、打印/另存PDF。

已清理指定品牌文案、标识、联系方式、推广和版权内容；示例根目录及终端用户名使用中性名称。原始PDF和带标记原图不包含在下载包中。

正文及图片已进行检索/OCR复核，主要交互通过浏览器离线检查，并已验证电脑和手机上的英文界面。本次语言更新保留所有图片和示例代码。7张技术插图只处理标识区域，其余像素核对不变。几个主要程序已作Python语法解析，未进行板卡硬件测试。详见 [核对报告](python-tutorial-report.json)。

HTML没有附带原教程引用但未随PDF提供的驱动、固件和项目源码包。操作时请核对本地资料位置、实物型号与引脚资料。
